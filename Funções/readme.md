# Lista - Funções

Exercícios práticos sobre funções em Python.

# Conteúdos

- Criação de funções com `def` e retorno de valores
- Parâmetros padrão, posicionais e nomeados
- `*args` e `**kwargs`
- Funções lambda, `map()` e `filter()`
- Funções recursivas e escopo de variáveis (`global`)
- Documentação com docstrings

# Como executar

```bash
python exercicios.py
```
