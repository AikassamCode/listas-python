# Lista - Listas (Exercícios de Fixação)

Exercícios práticos de fixação sobre listas em Python.

# Conteúdos

- Criação e preenchimento de listas com `input()`
- Iteração e exibição de elementos
- Busca de maior e menor valor com `max()` e `min()`
- Análise de notas com contagem condicional
- Cálculo de somatório e média

# Como executar

```bash
python exercicios.py
```
