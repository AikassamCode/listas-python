# Lista - Dicionários

Exercícios práticos sobre dicionários em Python.

# Conteúdos

- Criação com `{}` e `dict()`
- Acesso, inserção e alteração de valores
- Métodos: `.get()`, `.keys()`, `.values()`, `.items()`
- Métodos: `.pop()`, `.popitem()`, `.update()`, `.copy()`, `.clear()`, `.fromkeys()`
- Sistema de gerenciamento de usuários com menu interativo

# Como executar

```bash
python exercicios.py
```
