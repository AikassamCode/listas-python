# Lista - Matrizes

Exercícios práticos sobre matrizes em Python.

# Conteúdos

- Criação e manipulação de matrizes com listas aninhadas
- Soma, média por linha e soma de colunas
- Matriz identidade, transposta e simétrica
- Diagonal principal e secundária
- Multiplicação por escalar e entre matrizes
- Rotação 90° e busca de elementos

# Como executar

```bash
python exercicios.py
```
